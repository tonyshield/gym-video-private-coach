# 视频处理与拍摄

能原生看视频时优先原速观看，不为流程而转码。需本地抽帧或制作证据时再用本页。抽帧不识别动作或次数，实际查看画面才构成分析。

## 环境与最小抽帧

Python 3.10+、FFmpeg（含 ffprobe），无 Python 第三方包要求，不自动安装依赖。macOS 可自行用 `brew install ffmpeg`；其他系统按 FFmpeg 官方或发行版安装方法。

从 Skill 目录运行，路径替换成用户实际文件和新的私有目录：

```bash
python3 scripts/sample_video.py '/path/to/training.mov' \
  --out '/path/to/private-review/overview' --every 2
```

默认每 2 秒一帧、最多 48 帧；超限会报错，不偷偷稀疏采样。长视频缩小范围或明确提高间隔，说明检查范围。脚本只读本地文件，不上传、不覆盖原片，输出目录必须不存在。

定位目标组后加密采样，例如检查原片 12–15 秒：

```bash
python3 scripts/sample_video.py '/path/to/training.mov' \
  --out '/path/to/private-review/detail' \
  --start 12 --end 15 --every 0.1
```

实际用时替换成已观察的范围，不照搬示例。输出 `manifest.json` 与 JPEG；manifest 的 `requested_source_seconds` 是原文件开头起的请求定位秒数，**不是精确帧 PTS**，尤其可变帧率和编辑过的文件需谨慎。时间点标“约”，关键顺序回看视频或逐帧确认；不通过 `帧号 / 假定帧率` 换算手机原片时间。

FFmpeg 默认处理旋转信息；检查实际图像方向。manifest 的 encoded 尺寸可能不同于旋转后的输出。容器时长可能略超末帧，片尾最后一次请求若无可解码帧，会记录于 `skipped_requests` 并显示跳过数量，不补造图像。其他抽帧失败标 `incomplete`，不能说处理完成。输出保留文件名但不保存源绝对路径；仍可能包含脸或私人信息，不能当匿名数据发布。

## 如何看片

1. 看概览，确认人、动作、组次边界和遮挡，不用稀疏帧数重复。
2. 查看目标组的开始、中间和结束，候选问题附近加密；需要精确计数则逐次核对。
3. 关键重复覆盖下放/回程、转换、发力及完成；太稀疏时不判快速失控。
4. 同一原片的时间用于所有证据；裁剪后的相对时间加回起始偏移。多段来源同时写文件标识。

## 短片与标注

仅当对解释有帮助或用户要求时制作。用原片切出已核对的重复，保留原速；需要慢放再生成单独版本并标倍率。裁剪不能遮住支撑和负重，不修改原片。慢放通常不需要声音，不通过健身房碰撞声统计重复。

标记可见支撑点或轨迹前后，避免用骨架补全遮挡关节。人工确认坐标、身体左右、字幕和时间范围。输出后实际查看首、中、末帧；未验证不要称标注正确。没有工具时交付时间与关键帧，不虚构慢动作链接。

可选姿态工具没有首版依赖，不自动安装；引入前核对模型代码和权重的许可、设备要求及数据流。二维关键点不等于精确关节角度或损伤风险。

## 给用户的补拍建议

- 固定手机，尽量 1080p、30/60 fps、正常速度，不数码变焦；全身、脚、负重及支撑面全程入镜。
- 一段连续录一整组，含准备及结束；无需为了录像做到极限。
- 侧面较适合看前后位置和行程，前/后斜角补双侧差异；机位不能回答的问题不要硬判。
- 保持距离，不将手机放在杠铃落区、机器运动范围或通道；不为了避开遮挡撤保护装置。
- 尽量避开他人；录前记录动作、每只/总重量、计划组次及当前不适，下次尽量同机位。
